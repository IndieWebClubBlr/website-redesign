# IndieWebClub Bangalore Redesign — Implementation Plan

> **For the implementing agent:** Use the `executing-plans` skill to implement this plan task-by-task. Track progress with the checkboxes below.

**Goal:** Replace the dense, navigation-free homepage with a clear community front door, add dedicated Events, Writings, and About pages, and apply one accessible riso-zine visual system to every generated page.

**Architecture:** Keep the existing Python/Pystache static generator. Add two generated pages (`/events/`, `/writings/`), one Markdown page (`/about/`), a persistent four-link navigation, and one rewritten `assets/style.css`. Move the current homepage’s recent/weeknotes/on-this-day/random logic to `/writings/`, leaving the homepage as hero + next event + six latest posts + newsletter.

**Tech stack:** Python 3, Pystache, Markdown, Pygments, vanilla JS, one stylesheet, GitHub Pages. No framework, no new runtime dependency, no automated test suite.

**Spec:** `docs/superpowers/specs/2026-10-24-redesign-design.md`

**Working directory:** `/Users/abhinav/Projects/iwcb-website-redesign`

## Before you start

- Read the spec. Do not re-litigate the design decisions.
- Keep the HTML semantic and simple: native landmarks, headings, lists, articles, forms, and `<details>` only where it is the right element. Do not add presentational wrapper divs beyond the header/footer inner containers.
- No animation. The old logo wobble and `pointed-hand` emoji links are removed.
- No unit tests. The user inspects manually. Verify with the build, `basedpyright`, `black`, and the browser checklist at the end.
- Fonts are user-supplied. Put these files in `assets/fonts/`:
  - `anton-regular.woff2`
  - `gelasio-regular.woff2`
  - `gelasio-bold.woff2`
  - `courier-prime-regular.woff2`
  - `courier-prime-bold.woff2`
  - `OFL-Anton.txt`, `OFL-Gelasio.txt`, `OFL-Courier-Prime.txt`

  If they are not present yet, continue. The CSS falls back to Impact, Georgia, and Courier New, and the asset copier warns about missing files.
- Build command used throughout:

  ```sh
  nix-shell --run 'mkdir -p _site && python src/generator.py blogroll.opml _site --cache --cache-fallback'
  ```

- Serve command:

  ```sh
  nix-shell --run 'python scripts/serve.py 8000 ./_site/'
  ```
