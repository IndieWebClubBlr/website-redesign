# Self-hosted fonts

The site uses WOFF2 files from this directory, with the matching TTF files
as a fallback source for browsers that cannot load WOFF2.

| File | Family | Weight | Style | Replaces |
|---|---|---|---|---|
| `Anton-Regular.woff2` | Anton | 400 | normal | Impact |
| `Gelasio-Regular.woff2` | Gelasio | 400 | normal | Georgia |
| `Gelasio-Italic.woff2` | Gelasio | 400 | italic | Georgia italic |
| `Gelasio-Bold.woff2` | Gelasio | 700 | normal | Georgia bold |
| `Gelasio-BoldItalic.woff2` | Gelasio | 700 | italic | Georgia bold italic |
| `CourierPrime-Regular.woff2` | Courier Prime | 400 | normal | Courier New |
| `CourierPrime-Italic.woff2` | Courier Prime | 400 | italic | Courier New italic |
| `CourierPrime-Bold.woff2` | Courier Prime | 700 | normal | Courier New bold |
| `CourierPrime-BoldItalic.woff2` | Courier Prime | 700 | italic | Courier New bold italic |

All three families are licensed under the SIL Open Font License. The
matching licence texts are:

- `OFL-Anton.txt`
- `OFL-Gelasio.txt`
- `OFL-Courier-Prime.txt`

Sources:

- https://fonts.google.com/specimen/Anton
