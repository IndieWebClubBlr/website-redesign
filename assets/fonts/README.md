# Self-hosted fonts

Place these WOFF2 files in this directory. The site falls back to Impact,
Georgia, and Courier New until they are present.

| File | Family | Weight | Replaces |
|---|---|---|---|
| `anton-regular.woff2` | Anton | 400 | Impact |
| `gelasio-regular.woff2` | Gelasio | 400 | Georgia |
| `gelasio-bold.woff2` | Gelasio | 700 | Georgia bold |
| `courier-prime-regular.woff2` | Courier Prime | 400 | Courier New |
| `courier-prime-bold.woff2` | Courier Prime | 700 | Courier New bold |

All three families are licensed under the SIL Open Font License. Add the
matching licence files:

- `OFL-Anton.txt`
- `OFL-Gelasio.txt`
- `OFL-Courier-Prime.txt`

Sources:

- https://fonts.google.com/specimen/Anton
- https://fonts.google.com/specimen/Gelasio
- https://fonts.google.com/specimen/Courier+Prime
